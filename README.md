## What it is

NoteIt draws sticky notes directly on your screen, over any app. The space around them is transparent and click-through, so you keep working underneath. It lives in the system tray, and you control it with global shortcuts.

## Shortcuts

| Action | Shortcut |
| --- | --- |
| New note | `Ctrl + Shift + C` |
| Show / hide notes | `Ctrl + Shift + H` |
| Show / hide control bar | `Ctrl + Alt + B` |

## Install

Download the installer from [Releases](https://github.com/Peltre/NoteIt/releases/latest) and run it. It isn’t code-signed yet, so Windows SmartScreen will show a warning: click **More info**, then **Run anyway**.

Your notes are saved locally in `%APPDATA%\noteit`.
